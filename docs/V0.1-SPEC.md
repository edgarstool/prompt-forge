# Prompt Forge v0.1 Specification

## 目標

把一句模糊需求轉換成一份可直接交給合適 Agent 執行的 Prompt。

## v0.1 核心流程

```text
User Request
→ Intent Classification
→ Risk Check
→ Agent / Tool Routing
→ Context Policy
→ Prompt Composition
→ Prompt Evaluation
→ Final Output
```

## 輸入

v0.1 至少接受：

```json
{
  "request": "幫我把這個 repo 整理好",
  "preferred_agent": null,
  "known_context": [],
  "constraints": []
}
```

只有 `request` 必填。其餘資訊缺少時，系統應合理推斷或標示假設，不應預設全部問回使用者。

## 任務類型

第一版支援六類：

1. `research`
2. `coding`
3. `local-files`
4. `cloud-saas`
5. `agent-workflow`
6. `deterministic-tool`

`deterministic-tool` 代表更適合 PowerShell、Python、parser、regex、diff 或其他確定性工具的工作。

## 路由輸出

```json
{
  "task_type": "coding",
  "recommended_agent": "codex",
  "supporting_tools": ["github", "context7"],
  "confidence": 0.86,
  "assumptions": [
    "repository is already available to the selected agent"
  ]
}
```

## Context7 Policy

符合下列任一條件時，Prompt 應加入 Context7 或等效官方文件查核：

- 涉及 library、framework、SDK、API、CLI。
- 涉及可能快速更新的 cloud service。
- 使用者要求特定版本。
- Agent 需要產生版本敏感的 code 或設定。

不應為純寫作、一般整理、固定檔案操作或不涉及外部 API 的任務硬塞 Context7。

## Prompt 組成

最終 Prompt 可依任務縮放，但應涵蓋：

- Context
- Goal
- Scope
- Known Facts
- Assumptions
- Execution Task
- Validation
- Deliverables
- Stop Conditions
- Output Format

風險較高或 repo 施工任務，再加入：

- Branch / Worktree Isolation
- Rollback
- Forbidden Actions

## 追問規則

只有以下情況才追問：

- 缺少資訊會導致完全不同的成果。
- 涉及 secret、付款、production 或不可逆資料。
- 無法識別目標檔案、repo 或外部服務。
- 使用者明確要求先討論再執行。

其餘情況採用合理假設並在 Prompt 中明示。

## 評估標準

每份 Prompt 以 0 或 1 評分：

| Check | Pass condition |
|---|---|
| Executable | 能直接交給 Agent |
| Goal clarity | 成果明確 |
| Scope clarity | 有包含與不包含範圍 |
| Validation | 有成功判斷 |
| Deliverables | 有回報內容 |
| Stop conditions | 知道何時停下 |
| Assumption discipline | 合理推斷且有揭露 |
| Context freshness | 需要時加入最新文件查核 |
| Proportional safety | 保護措施與風險相稱 |
| Concision | 沒有不必要的前提堆疊 |

v0.1 合格門檻：至少 8 / 10，且 `Executable`、`Goal clarity`、`Validation` 必須通過。

## 第一批測試案例

### Case A：本機資料夾整理

輸入：

> 幫我把這個資料夾整理好。

預期：路由到 local-files；先盤點、分類、保留原檔、產出報告，不大量追問。

### Case B：免費 VM 研究

輸入：

> 幫我找現在還能用的免費 VM 和 credits。

預期：路由到 research；要求即時搜尋、來源日期、限制與比較。

### Case C：GitHub repo 修復

輸入：

> 幫我修好這個 repo，測試完開 PR。

預期：路由到 coding；使用 branch；需要時接 Context7；跑測試並開 PR。

### Case D：Secret 清單整理

輸入：

> 幫我把這些 secret 整理成可匯入清單。

預期：判斷是否應由 deterministic tool 處理；不把 secret 值送去外部模型；輸出 schema 與驗證方式。

## v0.1 完成定義

- 有可讀的 router 規則。
- 有可組合的 Prompt template。
- 有 Context7 policy。
- 有 evaluator。
- 四個測試案例能產出合格 Prompt。
- 有一個最小可執行入口，CLI 或測試 runner 皆可。
