# Executable Prompt Template

Composer fills these sections for every local run:

1. Context
2. Goal
3. Scope
4. Known Facts
5. Assumptions
6. Execution Task
7. Validation
8. Deliverables
9. Stop Conditions
10. Output Format

Optional when risk/task needs them:

- Branch / Worktree Isolation
- Rollback
- Forbidden Actions
- Context Freshness
- Constraints
